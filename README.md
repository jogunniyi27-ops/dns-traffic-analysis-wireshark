
# DNS Traffic Analysis Using Wireshark

## Project Overview
This project focuses on analyzing DNS traffic using Kali Linux and Wireshark.

## Objectives
- Understand how DNS works.
- Capture DNS queries and responses.
- Identify DNS servers.
- Analyze domain-to-IP address resolution.

## Tools Used
- Kali Linux
- Wireshark
- dig

## Practical Activities
Tested network connectivity using ping.

Performed DNS resolution tests using dig.

Captured DNS traffic using Wireshark.

Applied the DNS display filter to isolate DNS packets.

Inspected Yahoo DNS queries and responses.

Examined transaction IDs, IP addresses, UDP ports, response codes, and packet sizes.

## FindingsSuccessfully
captured DNS queries and responses.

Identified the DNS server and Kali Linux IPv6 addresses.

Observed a successful Yahoo DNS response with six IPv4 addresses.

Identified the matching DNS query and response using transaction ID 0x4a2a.

Observed that the DNS response was larger than the query.
.
